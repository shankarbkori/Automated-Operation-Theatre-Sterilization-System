ℹ️ How WhatsApp Alerts Work

This system uses the Twilio WhatsApp API to send automated alerts.

The backend's NotificationService fires a message whenever:
• A sterilization cycle is completed (Cycle Complete alert)
• A safety emergency is triggered (EMERGENCY alert)

To activate, configure your Twilio credentials in application.properties and add the recipient phone number above.
